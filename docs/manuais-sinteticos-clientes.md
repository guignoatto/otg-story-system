# Manuais sinteticos provisiorios dos clientes OTG

Estes perfis nao substituem um manual oficial de marca. Eles servem como ponto de partida para o MVP quando o restaurante ainda nao enviou PDF, brandbook ou guia visual.

Regra geral para todos:
- A IA nao pode recriar, redesenhar, completar, corrigir ou inventar logo, lettering, brasao, mascote, monograma, placa, embalagem ou marca fotografada.
- A IA deve usar fotos reais do restaurante como referencia principal.
- Nao inventar preco, horario, endereco, unidade, oferta, combo, telefone ou promessa comercial.
- Em Stories organicos, nao usar CTA de WhatsApp, botao falso, enquete desenhada, quiz desenhado, salve ou comente.
- Quando houver duvida operacional, bloquear a ideia ate a OTG confirmar no briefing.
